# constitution-rbe v2.5

Концептуальный проект конституции и свода законов для **greenfield-города «Город F»** на основе ресурсо-ориентированной экономики (RBE) Жака Фреско (The Venus Project).

**Пилот:** новый город 5–10 тыс. → 50–100 тыс. человек в Краснодарском крае.
**Переходная модель:** Гибрид F (безусловный минимум + трудовые баллы + дивиденды города).
**Цель:** полная RBE к 25–50 году.

> ⚠️ Это **концептуальный проект для обсуждения**, а не готовый к принятию юридический документ.

---

## Ключевые принципы

1. **RBE — цель, Гибрид F — переход.** Не выдавать переход за RBE.
2. **Спонсор — кредитор, не акционер.** Возврат из внешнего контура, royalty до потолка, наблюдательное место без решающего голоса.
3. **Неделимый минимум прав** — не отчуждается ни в одном режиме.
4. **ИИ с человеком в контуре.** Никаких окончательных принудительных решений ИИ.
5. **Три уровня голосования.** Технические решения не голосуются.
6. **Два контура экономики:** баллы внутри, деньги снаружи. Не конвертируются.
7. **Честность об остаточных рисках.** Никаких обещаний абсолютной защиты.
8. **Фальсифицируемость.** У каждой нормы — индикаторы и триггеры пересмотра.

## Метрики для спонсора (26 показателей)

**Экономика:** баланс ЧОПТ, автоматизация, самодостаточность.
**Экология:** энергия, вода, продовольствие, экослед.
**Социальные:** удовлетворённость, отток, разрыв в уровне жизни.
**Управление:** аудит, публикации, партнёрства.

**Индикаторы провала:**
- Отток >15% в год — модель не удерживает.
- Разрыв >4× — двухуровневое общество.
- Водный резерв <6 мес. — критическая уязвимость.
- Продовольственная самодостаточность <30% — зависимость.
- Энергозависимость >50% — риск шантажа.
