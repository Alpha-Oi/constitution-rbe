# constitution-rbe v2.0

Концептуальный проект конституции и свода законов для greenfield-города
на основе ресурсо-ориентированной экономики (RBE) Жака Фреско.

**Гибрид F:** безусловный минимум + трудовые баллы + дивиденды города.
**Пилот:** greenfield 5–10 тыс. → 50–100 тыс. в Краснодарском крае.

## Структура

- `SKILL.md` — мета-промпт скилла.
- `reference/` — 12 справочников.
- `experience/` — накопительный опыт.
- `constitution/` — модули проекта.

## Ключевые принципы

1. RBE — цель, Гибрид F — переход.
2. Спонсор — кредитор, не акционер.
3. Неделимый минимум прав.
4. ИИ с человеком в контуре.
5. Три уровня голосования.
6. Два контура: баллы внутри, деньги снаружи.

## Статус

Концептуальный проект. Не готов к принятию.
