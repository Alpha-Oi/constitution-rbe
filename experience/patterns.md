# Patterns

## Удачные формулировки
- «Ресурсы общие» → «доверительное управление в трасте».
- «Нет денег» → «внутренние баллы, не конвертируемые».
- «Нет политиков» → «совет экспертов + референдум».
- «Нет наказаний» → «реабилитация + минимум принуждения».

## Закрытые обходы
- Экспроприация → компенсация + право выхода.
- Company town → устав выше спонсора, траст.
- Долговое рабство → базовое жильё безусловно.
- Тирания большинства → три уровня голосования.
- Захват ИИ → human-in-the-loop, распределённый выключатель.
