# Модуль 47. Коммуникации и маркетинг
v1.0 | 2026-10-15

Привлечение жителей, партнёров, внимания.
См.: [29-communications.md](29-communications.md), [40-international-strategy.md](40-international-strategy.md).

## 1. Принципы

1. Честность - никакой лжи.
2. Прозрачность - всё открыто.
3. Скромность - без хайпа.
4. Научность - факты и цифры.
5. Плюрализм - разные мнения.
6. Никакой политики.
7. Никакой агрессии.
8. Уважение к критике.
9. Множественность каналов.
10. Долгосрочность.

## 2. Аудитории

### 2.1. Жители
- Идеалисты (RBE, экология).
- Специалисты (врачи, инженеры).
- Семьи с детьми.
- Молодые (22-35).
- Пенсионеры (опытные).
- Беженцы (защита).

### 2.2. Партнёры
- Спонсоры (фонды, инвесторы).
- Хост-страны (правительства).
- Технологические партнёры.
- Научные центры.
- Города-побратимы.

### 2.3. Публика
- СМИ.
- Исследователи.
- Студенты.
- Активисты.
- Широкая общественность.

## 3. Каналы

### 3.1. Собственные
- Сайт (город-ф.рф или аналог).
- Telegram-канал.
- YouTube-канал.
- GitHub (открытый код).
- X (Twitter) для международных.

### 3.2. Внешние
- Конференции.
- Форумы.
- Публикации в СМИ.
- Научные журналы.
- Подкасты.

### 3.3. Личные
- Прямые контакты.
- Письма.
- Презентации.
- Встречи.

## 4. Сайт

### 4.1. Структура
- Главная (миссия в 1 абзац).
- Проект (что, зачем, как).
- Документы (GitHub, презентация).
- Партнёрам (для спонсоров).
- Жителям (как присоединиться).
- Контакты.
- Блог (новости, мысли).

### 4.2. Принципы
- Простой дизайн.
- Быстрая загрузка.
- Мобильная версия.
- Многоязычность (русский, английский + местные).
- Открытые данные.

### 4.3. Стоимость
- Хостинг: 5-20 тыс. руб./год.
- Домен: 1-3 тыс. руб./год.
- Разработка: 50-200 тыс. (или сами).

## 5. Соцсети

### 5.1. Telegram
- Основной канал (русский).
- Новости проекта.
- Обсуждения.
- 3-5 постов в неделю.

### 5.2. YouTube
- Презентации (10-30 мин).
- Интервью.
- Экскурсии (когда город появится).
- 1-2 видео в месяц.

### 5.3. X (Twitter)
- Международная аудитория.
- Английский язык.
- Короткие новости.

### 5.4. LinkedIn
- Для партнёров и фондов.
- Профессиональный контент.

## 6. Контент

### 6.1. Типы
- Научные статьи.
- Аналитика.
- Презентации.
- Видео.
- Подкасты.
- Открытые данные.

### 6.2. Принципы
- Честность.
- Факты и цифры.
- Ссылки на источники.
- Плюрализм.
- Открытость.

## 7. PR

### 7.1. Работа со СМИ
- Пресс-релизы.
- Аккредитация журналистов.
- Интервью (по запросу).
- Ответы в течение 24 часов.

### 7.2. Конференции
- Собственные (1-2 в год).
- Участие во внешних (5-10 в год).
- Публикации в сборниках.

### 7.3. Кризисные коммуникации
- Быстрый ответ (2 часа).
- Публичность.
- Извинения при ошибках.
- Разбор после.

## 8. Красная команда

| Сценарий | Контрмера |
|----------|-----------|
| Дезинформация | Открытые данные |
| Сокрытие провалов | Обязательная публикация |
| Культ основателей | Запрет персонификации |
| Пропаганда | Плюрализм |
| Зависимость от медиа | Множественность каналов |
| Информационная атака | Быстрый ответ |
| Утечка данных | Шифрование |
| Хайп без содержания | Скромность |
