# Модуль 43. Отбор жителей
v1.0 | 2026-10-15

Отбор всех последующих жителей (не только первых 500).
См.: [06-first-settlers.md](06-first-settlers.md), [18-migration.md](18-migration.md).

## 1. Принципы

1. Добровольность.
2. Информированное согласие.
3. Право выхода.
4. Никакой дискриминации (раса, вера, пол, происхождение).
5. Приоритет - дефицитным специальностям.
6. Семьи с детьми - приоритет.
7. Проверка - минимальная, но обязательная.
8. Испытательный срок - 6 месяцев.
9. Отсев - возможен, но с уважением.
10. Адаптация - обязательная.

## 2. Критерии отбора

### 2.1. Обязательные
- Совершеннолетний (18+).
- Готовность подписать устав.
- Информированное согласие.
- Отсутствие тяжких преступлений.
- Медицинская пригодность (без опасных инфекций).

### 2.2. Приоритетные
- Дефицитные специальности (врач, инженер, агроном).
- Семьи с детьми.
- Молодые специалисты (22-35 лет).
- Волонтёры с опытом.
- Люди с идеей проекта (RBE).

### 2.3. Дисквалифицирующие
- Тяжкие преступления (убийство, насилие, наркотики).
- Психические расстройства с опасностью для окружающих.
- Активная пропаганда насилия, ненависти.
- Скрытая работа на спецслужбы (по факту обнаружения).

## 3. Процедура

### 3.1. Этапы
1. Заявка (онлайн или офлайн).
2. Проверка документов (1-2 недели).
3. Интервью (1-2 часа).
4. Проверка навыков (по специальности).
5. Проверка биографии (минимально - судимости).
6. Медицинский осмотр.
7. Информированное согласие.
8. Решение (одобрено / отказ / резерв).

### 3.2. Сроки
- От заявки до решения: 30-60 дней.
- От решения до приезда: 30-90 дней.
- Всего: 2-5 месяцев.

### 3.3. Кто решает
- Комиссия из 5 человек: HR, медик, юрист, представитель совета, психолог.
- Голосование - простое большинство.
- Апелляция - в совет координаторов.

## 4. Испытательный срок

### 4.1. Условия
- 6 месяцев с момента заселения.
- Все права, кроме участия в голосованиях.
- Базовое жильё и питание - гарантированы.
- Трудовые баллы - начисляются, но не тратятся.

### 4.2. Оценка
- Адаптация к уставу.
- Работа с сообществом.
- Вклад в общее дело.
- Соблюдение норм.
- Психическое состояние.

### 4.3. Результат
- **Одобрено** - полные права.
- **Продлено** - ещё 3 месяца (редко).
- **Отказ** - выезд без долга, компенсация.

## 5. Отсев

### 5.1. Когда
- Систематическое нарушение устава.
- Агрессия, насилие.
- Мошенничество, коррупция.
- Неспособность адаптироваться (редко).

### 5.2. Процедура
- Уведомление (за 30 дней).
- Право на защиту.
- Решение совета + суд.
- Апелляция.
- Выезд без долга.

### 5.3. Что запрещено
- Отсев по расе, вере, полу.
- Отсев за критику.
- Отсев без суда.
- Отсев детей (выезжают с родителями).

## 6. Квоты

### 6.1. По специальностям (для 10 тыс.)
| Специальность | Доля |
|---------------|------|
| Врачи, медсёстры | 5% |
| Инженеры | 10% |
| Агрономы, фермеры | 10% |
| Строители | 15% |
| Учителя, воспитатели | 8% |
| ИТ и наука | 12% |
| Услуги | 20% |
| Прочие | 20% |

### 6.2. По возрасту
- 18-25: 15%.
- 25-45: 50%.
- 45-65: 25%.
- 65+: 10%.

### 6.3. По составу
- Семьи с детьми: 40%.
- Пары без детей: 20%.
- Одиночки: 40%.

## 7. Адаптация

### 7.1. Программа
- 1-я неделя: знакомство с городом, уставом.
- 1-й месяц: наставник, обучение.
- 3-й месяц: первая оценка.
- 6-й месяц: полные права.

### 7.2. Что помогает
- Наставник из опытных жителей.
- Курсы местного языка.
- Культурная программа.
- Психолог.
- Сообщество по интересам.

### 7.3. Что мешает
- Языковой барьер.
- Культурные различия.
- Ностальгия.
- Одиночество.
- Ожидания vs реальность.

## 8. Красная команда

| Сценарий | Контрмера |
|----------|-----------|
| Коррупция при отборе | Ротация комиссии, аудит |
| Дискриминация | Жалоба, суд |
| Скрытые агенты | Проверка биографии |
| Иждивенцы | Испытательный срок |
| Конфликты новичков | Медиация, наставники |
| Отсев по ошибке | Апелляция, компенсация |
| Массовый приток | Квоты по годам |
| Отток после 6 мес | Анализ причин, улучшения |

- Отток после 6 месяцев.
