# Модуль 08. Безопасность

Режим: гибридный
Охват: greenfield в Краснодарском крае
Версия: v2.0
Дата: 2026-10-14

## Принцип
Для жителей, не против. Минимальны, подконтрольны, ограничены.

## Структуры
- Полиция: 1 на 500 (50–200).
- Пожарная: 1 на 2 000.
- Скорая: 1 на 1 000.
- Спасатели: 1 на 5 000.

## Ограничения
- Оружие — только при угрозе жизни.
- Задержание без суда — макс 48 ч.
- Слежка — только по суду.
- Все действия записываются.
- Независимый надзор.

## Кибербезопасность
Защита портала, данных, резервные системы, ручные протоколы.

## Оборона
Милиция (добровольцы). Договор с хост-страной. Нет армии. Нет ОМП.

## Оружие
Личное — только с лицензией. Регистрация. Психпроверка.

## Запрещено
Параллельные силовые структуры. Частные охранные фирмы с оружием. Слежка. Пытки. Коллективные наказания.
