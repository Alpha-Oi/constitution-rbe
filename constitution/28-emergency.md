# Модуль 28. Аварийные планы

Режим: гибридный
Охват: greenfield в Краснодарском крае
Версия: v2.4
Дата: 2026-10-14
Ограничение: концептуальный проект

## 1. Принцип
Город готовится к худшему, надеясь на лучшее.
Никакая авария не должна разрушить базовые права.

## 2. Категории аварий
| Категория | Примеры | Приоритет |
|-----------|---------|-----------|
| Природные | Засуха, наводнение, землетрясение | Вода, еда, жильё |
| Биологические | Пандемия, эпидемия скота | Здоровье, изоляция |
| Техногенные | Сбой ИТ, энергия, вода | Резервы, ручные протоколы |
| Внешние | Война, санкции, блокада | Автаркия, резервы |
| Внутренние | Конфликт, саботаж | Минимум прав, суд |
| Финансовые | Уход спонсора, крах | Резервы, консорциум |

## 3. Общие принципы
- Минимум прав не отменяется даже в аварии.
- Чрезвычайные полномочия — максимум 3 года.
- Суд работает всегда.
- Наблюдательный совет — работает.
- Публичность сохраняется.
- Ротация — не приостанавливается.

## 4. Аварийные протоколы

### 4.1. Вода
- Резерв 2 года.
- Приоритет: питьё → медицина → гидропоника → быт → производство.
- Ручные протоколы распределения.
- Публичные отчёты ежедневно.

### 4.2. Энергия
- Накопители 24–48 часов.
- Резервные генераторы 72 часа.
- Приоритет: медицина → вода → связь → жильё → производство.
- Отключения — по графику, публично.

### 4.3. Еда
- Резерв 1–2 года.
- Приоритет: дети → больные → пожилые → остальные.
- Гидропоника — работает в первую очередь.
- Внешние поставки — по плану.

### 4.4. Пандемия
- Изоляция по протоколам.
- Медицина в первую очередь.
- Вакцинация — добровольная, но карантин при отказе.
- Образование и работа — удалённо.
- Права не отменяются.

### 4.5. Сбой ИТ
- Ручные протоколы.
- Бумажный след.
- Резервные серверы.
- Восстановление — приоритет №1.

### 4.6. Война
- Милиция — добровольцы.
- Договор с хост-страной.
- Эвакуация по плану.
- Архив — в безопасном месте.

### 4.7. Уход спонсора
- Резервный фонд 2–3 года.
- Замена спонсора.
- Самофинансирование.
- Переход в автаркию по базовым нуждам.

## 5. Учения
- Раз в год — учения по одной категории.
- Публичные.
- С участием жителей.
- Разбор ошибок — обязателен.

## 6. Законы
- О чрезвычайных полномочиях.
- О резервах.
- О протоколах.
- О учениях.
