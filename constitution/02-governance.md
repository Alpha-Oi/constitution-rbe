# Модуль 02. Управление

Режим: гибридный
Охват: greenfield в Краснодарском крае
Версия: v2.0
Дата: 2026-10-14

## Четыре ветви

### Народное собрание (законодательная)
Все жители 18+. Три уровня голосования.

### Совет координаторов (исполнительная)
5–9 человек, срок 3 года, ротация, отзыв через петицию 10%.

### Суд (судебная)
Независимые судьи на 7 лет. Финансовая автономия.

### Наблюдательный совет (контрольная)
Жители + спонсор + хост + эксперты. Вето на нарушения устава.

## Предохранители
1. Ротация (макс 2 срока).
2. Отзыв (10% петиция).
3. Прозрачность.
4. Разделение.
5. Минимум прав не голосуется.
6. Независимый аудит.
7. Sunset clauses (макс 3 года для ЧС).

## Чрезвычайные полномочия
Только совет + подтверждение собрания в 72 часа. Макс 3 года.
