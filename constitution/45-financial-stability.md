# Модуль 45. Финансовая устойчивость
v1.0 | 2026-10-15

Что если источник дохода пропадёт.
См.: [07-finance.md](07-finance.md), [33-financial-model.md](33-financial-model.md).

## 1. Принципы

1. Диверсификация - не один источник.
2. Резервы - обязательно.
3. План Б - всегда.
4. Стресс-тесты - регулярно.
5. Прозрачность - все данные.
6. Приоритет базовым нуждам.
7. Сокращение без паники.
8. Никаких долгов без плана.

## 2. Диверсификация доходов

### 2.1. Источники (целевое)
| Источник | Доля | Риск |
|----------|------|------|
| Экспорт конопли | 25% | Средний |
| Продукты питания | 20% | Низкий |
| Вино, сыр | 15% | Средний |
| Услуги (наука) | 15% | Низкий |
| Данные, технологии | 10% | Средний |
| Экотуризм | 5% | Высокий |
| Прочее | 10% | Разный |

### 2.2. Правила
- Ни один источник >30%.
- Минимум 5 источников.
- Диверсификация по странам.
- Диверсификация по отраслям.
- Пересмотр ежегодно.

## 3. Резервы

### 3.1. Обязательные
| Резерв | Объём |
|--------|-------|
| Финансовый | 2-3 года операционных |
| Продовольствие | 1-2 года |
| Вода | 2 года |
| Лекарства | 6-12 мес. |
| Энергия | 48 часов |
| Запчасти критичные | 12 мес. |

### 3.2. Где хранить
- Продовольствие: склады внутри города.
- Вода: резервуары + подземные.
- Финансы: разные банки + крипта.
- Лекарства: аптечные склады.
- Запчасти: распределённые склады.

### 3.3. Правило
Резервы **не тратятся** на текущие нужды.
Только при чрезвычайной ситуации (по решению совета + собрания).

## 4. План Б

### 4.1. Если спонсор уходит
1. Активировать резервный фонд (2-3 года).
2. Найти замену (12 месяцев).
3. Сократить расходы на 30%.
4. Приоритет: вода, еда, медицина.
5. Заморозить стройку (кроме критичного).
6. Перейти на самофинансирование.

### 4.2. Если экспорт падает
1. Диверсифицировать рынки.
2. Снизить цены на 10-20%.
3. Увеличить внутреннее потребление.
4. Активировать резервы.
5. Сократить импорт.

### 4.3. Если санкции
1. Переключиться на альтернативных партнёров.
2. Автаркия по базовым нуждам.
3. Бартерные схемы.
4. Использовать криптовалюты (осторожно).

### 4.4. Если катастрофа
1. Чрезвычайный режим.
2. Резервы - в первую очередь.
3. Эвакуация (при необходимости).
4. Восстановление после.

## 5. Стресс-тесты

### 5.1. Регулярность
- Ежегодно - базовый тест.
- При изменении условий - внеплановый.
- Результаты - публичные.

### 5.2. Сценарии
| Сценарий | Влияние | Реакция |
|----------|---------|---------|
| Спонсор уходит | −30% доходов | Резерв + замена |
| Экспорт −50% | −50% доходов | Диверсификация |
| Санкции | −40% | Автаркия |
| Катастрофа | −70% | Чрезвычайный режим |
| Инфляция +20% | −15% | Индексация |

### 5.3. Показатели
- Финансовый резерв - месяцы.
- Долг - % от доходов.
- Диверсификация - индекс.
- Устойчивость - балл.

## 6. Красная команда

| Сценарий | Контрмера |
|----------|-----------|
| Зависимость от одного источника | Диверсификация |
| Трата резервов | Конституционный запрет |
| Скрытые долги | Аудит, публичность |
| Коррупция в финансах | Ротация, надзор |
| Финансовая пирамида | Прозрачность |
| Уход ключевого финансиста | Дублирование |
| Валютный кризис | Резервы в разных валютах |
| Санкции на банки | Крипта, бартер |
