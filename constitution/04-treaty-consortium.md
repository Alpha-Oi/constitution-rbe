# Модуль 04. Договор консорциума (L-10)

Режим: гибридный
Охват: greenfield в Краснодарском крае
Население: 5–10 тыс. → 50–100 тыс.
Версия: v2.6
Дата: 2026-10-14
Статус: черновик
Ограничение: концептуальный проект

Расширение `04-treaty-full.md`. Фиксирует **смешанный консорциум L-10** как основной
вариант спонсорства. Заменяет абстрактного «Спонсора» на конкретную структуру
из нескольких партнёров с разделением ролей.

---

## 1. Почему L-10

Сравнение вариантов из `experience/lessons.md`:

| Вариант | Совместимость с RBE | Устойчивость | Риск захвата |
|---------|---------------------|--------------|--------------|
| L-01 Акционер | нет | — | высокий |
| L-02 Кредитор | да | средняя | низкий |
| L-03 Кредитор + royalty | да | средняя | низкий |
| L-05 Консорциум | да | высокая | низкий |
| L-06 Суверенный фонд | с оговорками | средняя | средний |
| L-07 Tech-инвестор | с оговорками | низкая | высокий |
| L-08 Philanthropist | да | средняя | низкий |
| L-09 Госпрограмма | с оговорками | средняя | средний |
| **L-10 Смешанный консорциум** | **да** | **высокая** | **низкий** |

**L-10 выбирается потому что:**
- ни один партнёр не имеет контроля,
- устойчивость к выходу одного,
- разделение рисков,
- баланс интересов (деньги, земля, наука, репутация),
- соответствует RBE: никто не получает прибыль от внутренней экономики.

---

## 2. Состав консорциума

Пять ролей. Каждая — отдельный партнёр или группа.

| № | Роль | Что даёт | Что получает |
|---|------|----------|--------------|
| 1 | Финансовый | Деньги (кредит) | Возврат + royalty + доступ |
| 2 | Земельный | Земля (аренда/концессия) | Аренда + приоритетный доступ |
| 3 | Технологический | Оборудование, лицензии | Лицензионные отчисления + доступ |
| 4 | Научный | Исследования, экспертиза | Данные + публикации + патенты |
| 5 | Репутационный | Имя, связи, медиа | Демонстрация + репутация |

**Правило:** ни один партнёр не получает больше 25% голосов в наблюдательном совете.

## 3. Финансовый партнёр

### 3.1. Вклад
- Кредит: [сумма] в графике [приложение А].
- Обеспечение возврата: гарантии хост-страны.

### 3.2. Что получает
| Канал | Размер | Источник |
|-------|--------|----------|
| Возврат | 3–5% годовых | Внешний контур (экспорт) |
| Royalty | 10–15% выручки | Экспорт |
| Потолок | 2× от вложенного | — |
| После потолка | 0 | — |
| Доступ к продукции | По себестоимости | — |
| Наблюдательное место | 1 представитель | Без решающего голоса |

### 3.3. Что НЕ получает
- Долю в городе.
- Прибыль от внутренней экономики.
- Право менять устав.
- Право назначать руководство.
- Право владеть землёй и инфраструктурой.

### 3.4. Exit
- Односторонне: уведомление за 24 месяца.
- По согласию: в любой момент.
- При выходе: возврат по графику + замена партнёра.

## 4. Земельный партнёр

### 4.1. Вклад
- Земля: [площадь] га в [район].
- Форма: аренда на 49 лет / концессия / траст.
- Право водозабора: [объём] м³/год.
- Гарантии от изъятия.

### 4.2. Что получает
| Канал | Размер |
|-------|--------|
| Арендная плата | Фиксированная + индексация |
| Приоритетный доступ к продукции | По себестоимости |
| Наблюдательное место | 1 представитель |
| Возврат улучшений | По окончании срока |

### 4.3. Что НЕ получает
- Право менять назначение земли.
- Право продавать без согласования.
- Право на инфраструктуру города.

### 4.4. Exit
- При систематических нарушениях — расторжение.
- При выходе — компенсация улучшений.

## 5. Технологический партнёр

### 5.1. Вклад
- Оборудование: лаборатории, гидропоника, производство.
- Лицензии на технологии.
- Обучение персонала.
- Поддержка 5 лет.

### 5.2. Что получает
| Канал | Размер |
|-------|--------|
| Лицензионные отчисления | % от продукции |
| Доступ к разработкам города | Бесплатно |
| Наблюдательное место | 1 представитель |
| Приоритет в закупках | При равных условиях |

### 5.3. Что НЕ получает
- Исключительные права.
- Патенты на разработки города.
- Контроль за лабораториями.

### 5.4. Exit
- По согласованию.
- При выходе: лицензии сохраняются, поддержка завершается.

---

## 6. Научный партнёр

### 6.1. Вклад
- Исследования по темам города.
- Экспертиза.
- Обучение кадров.
- Независимая оценка.

### 6.2. Что получает
| Канал | Размер |
|-------|--------|
| Доступ к данным | Анонимизированным, публичным |
| Соавторство в публикациях | По вкладу |
| Совместные патенты | 50/50 |
| Наблюдательное место | 1 представитель |
| Стажировки | Приоритет |

### 6.3. Что НЕ получает
- Исключительные права на данные.
- Право влиять на политику города.
- Право публиковать без согласия (кроме анонимных данных).

### 6.4. Exit
- По согласованию.
- Публикации завершаются.
- Совместные патенты сохраняются.

### 7.1. Вклад
- Имя, бренд, публичная поддержка.
- Связи, медиа, дипломатия.
- Привлечение других партнёров.

### 7.2. Что получает
| Канал | Размер |
|-------|--------|
| Право на демонстрацию кейса | — |
| Наблюдательное место | 1 представитель |
| Приоритетный доступ | К продукции |
| Упоминание в публикациях | — |

### 7.3. Что НЕ получает
- Право на бренд города.
- Исключительные права на медиа.
- Контроль за коммуникацией.

### 7.4. Exit
- Свободный.
- Публичное объявление.
- Сохранение права на упоминание прошлого участия.

## 9. Распределение выгод

### 9.1. Внутренний контур (баллы)
Только для жителей. Партнёры не получают баллы.

### 9.2. Внешний контур (деньги)
Приоритет распределения выручки от экспорта:
1. Возврат кредита финансовому партнёру.
2. Royalty.
3. Лицензионные отчисления.
4. Аренда земли.
5. Операционные расходы города.
6. Резервы.
7. Развитие.

### 9.3. Целевое распределение (пример)
Для годовой выручки X:
- Возврат: 30–40% от X.
- Royalty: 10–15%.
- Лицензии: 3–5%.
- Аренда: 3–5%.
- Операционные: 20–30%.
- Резервы: 10–15%.
- Развитие: 5–10%.

`[ПРОВЕРИТЬ: цифры условные]`

## 10. Замена партнёров

### 10.1. Процедура
1. Партнёр объявляет выход.
2. Город ищет замену (срок 12 месяцев).
3. Замена одобряется собранием жителей.
4. Обязательства переходят к новому партнёру.
5. При отсутствии замены — пересмотр договора.

### 10.2. Критерии замены
- Совместимость с RBE.
- Отсутствие конфликта интересов.
- Финансовая устойчивость.
- Репутация.
- Согласие хост-страны.

---

## 11. Защита от захвата

| Риск | Механизм защиты |
|------|-----------------|
| Финансовый партнёр требует долю | Устав выше, договор запрещает |
| Партнёры сговариваются | Разные интересы, ротация |
| Хост-страна меняет режим | Договор, международный арбитраж |
| Один партнёр финансирует больше | Ограничение доли влияния |
| Партнёр покупает голоса | Тайное голосование, аудит |
| Скрытый контроль через третьих лиц | Проверка конечных бенефициаров |

**Главное правило:** устав выше консорциума.

---

## 12. Форма договора

### 12.1. Структура
1. Рамочный договор — цели, принципы, состав.
2. Приложения А–Е — конкретные условия по каждому партнёру.
3. Отдельные соглашения — операционные.
4. Протоколы — изменения.

### 12.2. Рамочный договор содержит
- Предмет.
- Срок (25 лет).
- Территория.
- Правовой режим.
- Состав консорциума.
- Доли влияния.
- Распределение выгод.
- Exit-стратегии.
- Споры и арбитраж.
- Форс-мажор.
- Публичность.

### 12.3. Публичность
Договор публикуется полностью, кроме:
- коммерческой тайны партнёров (раскрывается через 5 лет),
- персональных данных,
- вопросов безопасности (по суду).

## 14. Остаточные риски

- Сложность координации между партнёрами.
- Конфликты интересов.
- Долгие переговоры.
- Зависимость от внешних условий.
- Разные горизонты планирования (финансовый — 5 лет, город — 25).
- Геополитика.
