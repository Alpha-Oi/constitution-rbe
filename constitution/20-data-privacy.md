# Модуль 20. Данные и приватность (полный)

Режим: гибридный
Охват: greenfield в Краснодарском крае
Версия: v2.9
Дата: 2026-10-14
Ограничение: концептуальный проект

## 1. Принципы

1. **Данные — принадлежат человеку.**
2. **Запрет слежки.**
3. **Запрет социального рейтинга.**
4. **Локальное хранение** по умолчанию.
5. **Шифрование** — обязательно.
6. **Право на анонимность** в публичных местах.
7. **Право на удаление.**
8. **Право на забвение.**
9. **Право на портативность.**
10. **Никакой продажи данных.**

## 2. Что считается персональными данными

- Имя, возраст, пол.
- Адрес, контакты.
- Биометрия.
- Медицина.
- Финансы.
- Предпочтения.
- Переписка.
- Местоположение.
- Поведение.

## 3. Права

1. **Доступ** к своим данным.
2. **Исправление** ошибок.
3. **Удаление** данных.
4. **Забвение** — через 5 лет.
5. **Портативность** — перенос.
6. **Отказ** от сбора.
7. **Возражение** против обработки.
8. **Жалоба** — независимый орган.

## 4. Запрещено

- Социальный рейтинг.
- Скрытое наблюдение.
- Массовая биометрия без суда.
- Продажа данных.
- Передача третьим лицам без согласия.
- Профилирование без согласия.
- Автоматические решения без человека.
- Слежка за перемещениями.
- Прослушка без суда.

## 5. Разрешено

- Локальное хранение.
- Анонимизация для статистики.
- Сбор с согласия.
- Экстренные случаи — по суду.
- Данные для медицины — с согласия.
- Научные данные — анонимизированные.
- Публичные данные — открытые.

## 6. Портал жителя

- Добровольный.
- Право отказа.
- Бумажная альтернатива.
- Прозрачность кода.
- Аудит.
- Локальное хранение ключей.
- Шифрование.

## 7. Идентификация

- Идентификация — обязательна.
- Биометрия — опциональна.
- Множественные методы.
- Право на анонимность в публичных местах.
- Запрет на единый реестр.

## 8. Медицинские данные
