# Модуль 11. Архитектура и жильё

Режим: гибридный
Охват: greenfield в Краснодарском крае
Версия: v2.3
Дата: 2026-10-14
Ограничение: концептуальный проект

## 1. Принцип
Город — для людей, а не для машин. Плотность умеренная. Зелёные зоны — обязательны. Костробетон — приоритетный материал.

## 2. Зонирование
| Зона | Доля |
|------|------|
| Жилая | 40% |
| Производство | 15% |
| Агро | 20% |
| Рекреация | 15% |
| Общественная | 10% |

## 3. Типы жилья
| Тип | Площадь | Кому |
|-----|---------|------|
| Базовое | 20–30 м² | Безусловно |
| Стандартное | 40–70 м² | За баллы |
| Расширенное | 70–120 м² | За баллы |
| Дом с участком | 100–200 м² | За баллы |

Разница между уровнями — минимальна. Никаких дворцов.

## 4. Материалы
- Костробетон — приоритет.
- Дерево, металл, стекло — вторично.
- Бетон — для несущих.
- Утеплитель — конопляная костра.

## 5. Ключевые нормы
- Доступность для инвалидов.
- Пожарная безопасность.
- Эвакуация — не более 3 минут.
- Пешеходная доступность — 15 минут до всего.
- Общие пространства — обязательны.
- Зелёные зоны — не менее 30% площади.

## 6. Законы
- О жилье.
- О градостроительстве.
- О доступной среде.
- О сохранении зелёных зон.

## 7. Остаточные риски
Уплотнение, нехватка земли, дорогой ремонт, конфликты соседей.
