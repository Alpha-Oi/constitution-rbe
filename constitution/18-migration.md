# Модуль 18. Миграция и гражданство (полный)

Режим: гибридный
Охват: greenfield в Краснодарском крае
Версия: v2.9
Дата: 2026-10-14
Ограничение: концептуальный проект

## 1. Принципы

1. **Добровольное присоединение.**
2. **Информированное согласие.**
3. **Право выхода.**
4. **Никаких депортаций**, кроме угрозы безопасности (по суду).
5. **Дети — под защитой.**
6. **Язык — русский**, поддержка изучения.
7. **Беженцы** — защита.
8. **Никакой дискриминации.**

## 2. Категории

| Категория | Права | Как получить | Срок |
|-----------|-------|--------------|------|
| Житель | Полные | Отбор + согласие | Постоянно |
| Гость | Минимум | Визит | До 90 дней |
| Работник | Ограниченные | Контракт | По контракту |
| Беженец | Защита | По закону | Временно |
| Гражданин | То же, что житель | 5 лет проживания | Постоянно |

## 3. Отбор жителей

### 3.1. Критерии
- Готовность подписать устав.
- Профессиональные навыки.
- Мотивация.
- Готовность к переходному периоду.
- Отсутствие тяжких преступлений.

### 3.2. Процедура
1. Заявка.
2. Интервью.
3. Проверка навыков.
4. Проверка биографии (минимально).
5. Информированное согласие.
6. Испытательный срок — 6 месяцев.
7. Полные права.

### 3.3. Квоты
- По специальностям — приоритет дефицитным.
- По возрасту — сбалансированно.
- По семьям — приоритет.

## 4. Гости

- Виза до 90 дней.
- Проживание — в гостиницах.
- Без права на баллы.
- Без права на безусловный минимум (кроме экстренной помощи).
- Регистрация — обязательно.

## 5. Работники

- Контракт с городом или предприятием.
- Проживание — в общежитиях.
- Оплата — по договору (рубли или баллы).
- Без права на дивиденды.
- Без права на безусловный минимум.
- Медицинская помощь — экстренная.

## 6. Беженцы

- Признание — через суд.
- Проживание — временное.
- Базовые права — гарантированы.
- Помощь — адаптация, язык.
- Дети — школа.
- Возвращение — добровольное.
- Никаких лагерей внутри города.

## 7. Гражданство города

- Постоянное проживание 5 лет.
- Знание устава.
- Отсутствие нарушений.
- Желание остаться.
- Присяга (по желанию).

**Гражданство города ≠ гражданство хост-страны.**

## 8. Право выхода

- Свободное.
- Без долга.
- Без потери личных вещей.
- С публичным подтверждением.
- Документы о вкладе.
- 30 дней на выезд.

## 9. Депортация

**Возможна только:**
- По решению суда.
- При угрозе безопасности.
- При систематических нарушениях.
- С правом обжалования.
- С уважением к правам.

**Запрещено:**
- Массовые депортации.
- Депортация детей.
- Депортация беженцев в опасные страны.
