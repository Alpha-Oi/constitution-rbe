# Модуль 17. Старость, инвалидность, смерть (полный)

Режим: гибридный
Охват: greenfield в Краснодарском крае
Версия: v2.9
Дата: 2026-10-14
Ограничение: концептуальный проект

## 1. Принципы

1. **Достойная жизнь до конца.**
2. **Уход — часть минимума.**
3. **Никакой стигмы.**
4. **Самоопределение** — до конца.
5. **Паллиатив — бесплатно.**
6. **Эвтаназия — добровольная** при неизлечимой болезни.
7. **Похороны — бесплатно.**
8. **Память** — сохраняется.

## 2. Пожилые

### 2.1. Базовое
- Безусловный минимум — сохраняется.
- Медицина — бесплатна.
- Уход — по потребности.
- Труд — по желанию.
- Баллы — за труд.

### 2.2. Пенсии
- Как таковой нет.
- Есть безусловный минимум.
- Трудовые баллы — накопленные.
- Дивиденды — равны для всех.

### 2.3. Инфраструктура
- Дома престарелых — по желанию, бесплатно.
- Уход на дому — бесплатно.
- Клубы для пожилых.
- Транспорт — бесплатный.
- Здравоохранение — приоритет.

## 3. Инвалидность

### 3.1. Права
- Базовое жильё — адаптировано.
- Медицина — бесплатна.
- Помощь — по потребности.
- Баллы за уход — начисляются.
- Труд — по силам.
- Никакой дискриминации.

### 3.2. Поддержка
- Транспорт — доступный.
- Работа — по возможностям.
- Реабилитация — бесплатно.
- Технические средства — бесплатно.
- Сопровождение.

### 3.3. Типы
- Физическая — пандусы, лифты.
- Сенсорная — тактильная, визуальная.
- Ментальная — сопровождение.
- Хронические — медицина.

## 4. Смерть

### 4.1. Естественная
- Хоспис — бесплатно.
- Паллиатив — приоритет.
- Обезболивание — обязательно.
- Психологическая поддержка — семье.
- Духовная — по желанию.

### 4.2. Эвтаназия

**Добровольная, при условиях:**
- Неизлечимая болезнь.
- Невыносимые страдания.
- Осознанное решение (18+).
- Подтверждение 2 врачами + комиссией.
- Согласие суда.
- Ожидание 30 дней.
- Право отменить в любой момент.

**Запрещено:**
- По просьбе родственников.
- Для детей.
- При психических расстройствах.
- По экономическим причинам.

### 4.3. Похороны
- Бесплатно.
- Скромно.
- По вере — по желанию.
- Кремация или погребение.
- Памятник — по желанию семьи.

### 4.4. Завещание
- Свободное.
- Без долгов.
- Ясное.
- Публичное (в части имущества).
- Оспаривание — через суд.

## 5. Хоспис

- Отдельно от больницы.
- Уютная среда.
- Круглосуточный уход.
- Семья — может жить рядом.
- Духовная поддержка.
- Бесплатно.

## 6. Память

- Архив жизней — по желанию.
- Публичное признание вклада.
- Никаких обязательных ритуалов.
- Дни памяти — по решению собрания.
