# Модуль 19. Свобода совести (полный)

Режим: гибридный
Охват: greenfield в Краснодарском крае
Версия: v2.9
Дата: 2026-10-14
Ограничение: концептуальный проект

## 1. Принципы

1. **Свобода верить, не верить, менять.**
2. **Никакой государственной религии.**
3. **Никакой государственной идеологии.**
4. **Религиозные организации — добровольные.**
5. **Религиозное образование — только по желанию.**
6. **Праздники — многокультурные.**
7. **Никакого финансирования религии из бюджета.**
8. **Защита детей** от давления.
9. **Уважение к атеистам.**
10. **Диалог** между сообществами.

## 2. Права

1. **Исповедовать** любую религию.
2. **Не исповедовать** никакой.
3. **Менять** религию.
4. **Объединяться** в религиозные группы.
5. **Отправлять обряды** (если не нарушают права).
6. **Отказываться** от религиозных обрядов.
7. **Воспитывать детей** в своей вере (без принуждения).

## 3. Религиозные организации

### 3.1. Регистрация
- Добровольная.
- Публичный реестр.
- Отчётность — минимальная.
- Налоговые льготы — при социальной работе.

### 3.2. Права
- Свободно отправлять обряды.
- Иметь здания.
- Вести благотворительность.
- Участвовать в диалоге.

### 3.3. Ограничения
- Не финансируются из бюджета.
- Не ведут обязательное обучение.
- Не влияют на управление.
- Не нарушают минимум прав.

## 4. Праздники

- **Общие:** Новый год, День города.
- **Религиозные:** по выбору сообществ.
- **Национальные:** по желанию.
- **Выходные:** религиозные — по согласованию.
- **Никаких обязательных** для всех.

## 5. Обряды

### 5.1. Разрешены
- Молитвы.
- Посты (добровольные).
- Праздники.
- Брачные обряды (дополнительно к гражданским).
- Похоронные обряды.
- Обрезание — только медицинское (до 18 — запрещено).

### 5.2. Запрещены
- Обрезание детей без медпоказаний.
- Ритуалы, нарушающие права.
- Жертвоприношения.
- Принуждение.
- Экзорцизм без согласия.

## 6. Образование

- Религиозное — только по желанию.
- В школах — не обязательно.
- Воскресные школы — свободно.
- Вузы — свободно.
- Никакого давления.
- Атеизм — как альтернатива.

## 7. Защита детей

- До 14 лет — согласие родителей (но ребёнок не обязан участвовать).
- С 14 лет — своё решение.
- Никакого принуждения.
- Никаких обрядов, наносящих вред.
- Право на отказ.

## 8. Диалог

- Межрелигиозный совет — при городе.
- Публичные обсуждения.
- Образование о религиях.
- Никакой прозелитической пропаганды в общественных местах.

## 9. Атеизм

- Полностью защищён.
- Никакой дискриминации.
- Право не участвовать в обрядах.
- Право на альтернативу.
