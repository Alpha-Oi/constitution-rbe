# Модуль 13. Отходы и санитария

Режим: гибридный
Охват: greenfield в Краснодарском крае
Версия: v2.3
Дата: 2026-10-14
Ограничение: концептуальный проект

## 1. Принцип
Замкнутые циклы. Отходы — ресурс, не мусор.

## 2. Категории
| Категория | Обработка |
|-----------|-----------|
| Органика | Компост, биогаз |
| Бумага | Переработка |
| Металл | Переработка |
| Стекло | Переработка |
| Пластик | Минимизация, переработка |
| Опасные | Отдельно, изоляция |
| Сточные воды | Очистка, возврат |

## 3. Ключевые нормы
- Раздельный сбор — обязателен.
- Никаких свалок на территории города.
- Опасные отходы — не хранятся.
- Серая вода — 60–80% возврата.
- Биогаз — в энергосистему.

## 4. Законы
- Об отходах.
- О санитарии.
- О сточных водах.
- О биогазе.

## 5. Остаточные риски
Аварии, дефицит мощностей, отставание переработки.
