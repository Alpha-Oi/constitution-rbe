# Модуль 44. Управление проектом
v1.0 | 2026-10-15

Управление проектом до запуска города.
См.: [25-roadmap.md](25-roadmap.md), [02-governance.md](02-governance.md).

## 1. Принципы

1. Прозрачность решений.
2. Ротация ролей.
3. Коллегиальность.
4. Персональная ответственность.
5. Документирование всего.
6. Публичность (кроме конфиденциального).
7. Скорость (решения за 7-14 дней).
8. Обратная связь.
9. Никаких «вечных» лидеров.
10. Готовность к провалу.

## 2. Роли в команде

### 2.1. Инициатор
- Запускает проект.
- Представляет публично.
- Не имеет особых прав после запуска.
- Ротация - каждые 2 года.

### 2.2. Координатор проекта
- Оперативное управление.
- Связь с партнёрами.
- Срок - 2 года, продление 1 раз.
- Отзыв - 2/3 команды.

### 2.3. Функциональные лидеры
- Юрист.
- Финансист.
- Архитектор.
- Агроном.
- Инженер-энергетик.
- ИТ-специалист.
- Коммуникатор.
- HR.

### 2.4. Совет проекта
- 5-9 человек.
- Стратегические решения.
- Ротация.
- Публичность заседаний.

### 2.5. Наблюдатели
- Спонсор (1 место).
- Хост-страна (1 место).
- Независимые эксперты (2 места).
- Без права решающего голоса.

## 3. Встречи и решения

### 3.1. Типы встреч
| Встреча | Частота | Кто |
|---------|---------|-----|
| Оперативка | Еженедельно | Команда |
| Стратегическая | Ежемесячно | Совет |
| Общая | Ежеквартально | Все |
| Кризисная | По необходимости | Совет + лидеры |
| Внешняя | По графику | С партнёрами |

### 3.2. Принятие решений
**Оперативные** (1-7 дней):
- Координатор + 1 лидер.
- Документируется.
- Публикуется.

**Стратегические** (7-30 дней):
- Совет проекта.
- Обсуждение.
- Голосование (простое большинство).
- Публикация.

**Ключевые** (30-90 дней):
- Все + наблюдатели.
- Публичное обсуждение.
- Голосование (2/3).
- Возможность вето наблюдателей (только по уставу).

### 3.3. Протоколы
- Все встречи - протокол.
- Публикация в течение 3 дней.
- Хранение - бессрочно.
- Доступ - открытый.

## 4. KPI

### 4.1. Этап 0 (проектирование)
- Готовность устава - 100%.
- Подписанные договоры - 3+.
- Готовность презентации - 100%.
- Команда - 5+ человек.

### 4.2. Этап 1 (стройка)
- Участок - куплен/арендован.
- Инфраструктура - 50%+.
- Жильё для 500 - готово.
- Финансирование - 100%.

### 4.3. Этап 2-3 (рост)
- Жители - по плану.
- Экспорт - растёт.
- Автономия - 50%+.
- Отток - <5%/год.

### 4.4. Этап 4-5 (демонстрация)
- Население - 30-100 тыс.
- Окупаемость - достигнута.
- Возврат спонсору - по графику.
- Публикации - 10+/год.

## 5. Документооборот

### 5.1. Принципы
- Единое хранилище (GitHub).
- Открытый доступ (кроме конфиденциального).
- Версионирование.
- Автоматический backup.
- Единый формат (Markdown).

### 5.2. Категории документов
| Категория | Доступ | Срок хранения |
|-----------|--------|---------------|
| Устав, законы | Публичный | Бессрочно |
| Протоколы встреч | Публичный | Бессрочно |
| Финансы | Публичный | Бессрочно |
| Договоры | Публичный (кроме тайны) | Бессрочно |
| Переписка | Внутренний | 5 лет |
| Персональные данные | Конфиденциальный | По закону |
| Коммерческая тайна | Ограниченный | До 5 лет |
