# Модуль 23. Внешние связи

Режим: гибридный
Охват: greenfield в Краснодарском крае
Версия: v2.4
Дата: 2026-10-14
Ограничение: концептуальный проект

## 1. Принцип
Кооперация без ООН. Двусторонние договоры. Города-побратимы.
Никаких военных блоков. Наука и торговля — вне политики.

## 2. Каналы связи
| Канал | Что даёт | Ограничения |
|-------|----------|-------------|
| Хост-страна | Правовая база, дипломатия | Через неё |
| Города-побратимы | Обмен опытом, культурой | Двусторонне |
| Научные партнёрства | Исследования, обмен | Без политики |
| Торговые договоры | Экспорт, импорт | Бартер + деньги |
| Международные фонды | Гранты, поддержка | Без условий контроля |

## 3. Запрещено
- Использовать ООН как орган легитимности.
- Вступать в военные блоки.
- Размещать иностранные базы.
- Заключать договоры, ограничивающие устав.
- Передавать данные жителей за границу.

## 4. Приоритеты
1. Хост-страна и её регионы.
2. Соседние страны (через хост).
3. Другие RBE-проекты.
4. Научные центры.
5. Международные организации (не ООН).

## 5. Санкции и давление
- Диверсификация партнёров.
- Резервы.
- Автаркия по базовым нуждам.
- Публичная позиция нейтралитета.

## 6. Законы
- О внешних договорах.
- О дипломатической службе.
- О защите от санкций.
- О данных за границей.

## 7. Красная команда
| Сценарий | Контрмера |
|----------|-----------|
| Санкции | Диверсификация, резервы |
| Шантаж | Автаркия по базе |
| Шпионаж | Открытость как защита |
| Информационная война | Прозрачность |
| Изоляция | Научные партнёрства |

## 8. Остаточные риски
Геополитика, шантаж, утечка технологий, зависимость от одного партнёра.
