# Модуль 23. Внешние связи (полный)

Режим: гибридный
Охват: greenfield в Краснодарском крае
Версия: v2.9
Дата: 2026-10-14
Ограничение: концептуальный проект

## 1. Принципы

1. **Кооперация без ООН.**
2. **Двусторонние договоры.**
3. **Города-побратимы.**
4. **Никаких военных блоков.**
5. **Наука и торговля — вне политики.**
6. **Прозрачность договоров.**
7. **Никаких баз на территории.**
8. **Данные жителей — не вывозятся.**
9. **Нейтралитет** в конфликтах.
10. **Мирное разрешение споров.**

## 2. Каналы

| Канал | Что даёт | Ограничения |
|-------|----------|-------------|
| Хост-страна | Правовая база, дипломатия | Через неё |
| Города-побратимы | Обмен опытом, культурой | Двусторонне |
| Научные партнёрства | Исследования, обмен | Без политики |
| Торговые договоры | Экспорт, импорт | Бартер + деньги |
| Международные фонды | Гранты, поддержка | Без условий контроля |
| Университеты | Образование, наука | Без идеологии |

## 3. Запрещено

- Использовать ООН как орган легитимности.
- Вступать в военные блоки.
- Размещать иностранные базы.
- Заключать договоры, ограничивающие устав.
- Передавать данные жителей за границу.
- Участвовать в санкциях против третьих стран.
- Принимать условия, противоречащие минимуму прав.

## 4. Приоритеты

1. Хост-страна и её регионы.
2. Соседние страны (через хост).
3. Другие RBE-проекты.
4. Научные центры.
5. Международные организации (не ООН).
6. Города-побратимы.

## 5. Дипломатическая служба

- Минимум — 3–5 человек. [ПРОВЕРИТЬ]
- Работа через хост-страну.
- Публичные отчёты.
- Ротация.
- Аудит.

## 6. Экспорт

- Продукция: конопля, композиты, вино, сыр.
- Услуги: наука, консалтинг, обучение.
- Данные: анонимизированные.
- Технологии: открытые.

## 7. Импорт

- Критичные товары: электроника, лекарства.
- Правило: ≥3 поставщика на товар.
- Резервы: 6–12 месяцев.
- Проверка качества.
- Диверсификация.

## 8. Санкции и давление

- Диверсификация партнёров.
- Резервы.
- Автаркия по базовым нуждам.
- Публичная позиция нейтралитета.
- Арбитраж.

## 9. Города-побратимы

- Обмен делегациями.
- Культурные программы.
- Научные обмены.
- Экономические связи.
- Минимум — 3 города. [ПРОВЕРИТЬ]
