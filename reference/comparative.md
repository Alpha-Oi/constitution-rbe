# Сравнительно-правовая опора

Для каждой нормы: аналог в конституциях, совместимость с международным правом, уроки.

## Источники (проверить)
- Конституции: США, Германия, Франция, Швейцария, Индия, Бразилия, ЮАР.
- Международные акты: ВДПЧ, МПГПП, МПЭСКП, ЕКПЧ.
- ИИ: ЮНЕСКО, Регламент ЕС.

Без поиска — только метки [ПРОВЕРИТЬ].
