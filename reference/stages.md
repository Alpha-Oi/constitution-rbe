# Шаблоны этапов

## Общая структура
1. Шапка (режим, охват, версия, дата, статус, ограничение).
2. Содержание.
3. Остаточные риски.
4. Открытые вопросы.
5. Кандидаты в уроки (0–3).

## Этапы
- −1: теория перехода.
- 0: допущения.
- Ворота: реализуемость.
- 1: принципы.
- 2: каркас.
- 3: текст.
- 4: законы.
- 5: красная команда.
