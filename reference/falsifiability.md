# Фальсифицируемость

Для каждой нормы:
- Индикатор успеха.
- Индикатор провала.
- Ранний сигнал.
- Триггер пересмотра.
- Срок (не более 10 лет).

Норма без индикаторов — декларация, помечается [ПРОВЕРИТЬ].
