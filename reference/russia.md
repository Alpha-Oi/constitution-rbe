# Особенности РФ

## Факторы
- Федеративное устройство.
- Конституционные поправки.
- Права и свободы (глава 2).
- Судебная система.
- Экономическая модель.
- Природные ресурсы.
- Международные обязательства.
- Демография.
- Региональные различия.

## Правила
- Факты — с меткой [ПРОВЕРИТЬ].
- Не оценивать власть.
- Пилот по умолчанию — город.
